# Код и техническая документация

Техническая документация instagram-planner. Внутри она организована по
областям, а внутри области — по типам
[Diátaxis](documentation.md#diataxis-types): `tutorial`, `how-to`,
`reference`, `explanation`.

- [Правила ведения документации](documentation.md)
- Архитектурные решения (`adr/`) — появятся с первым ADR

**Ни одна область ещё не описана.** Кода пока нет: `src/` — шаблон Vite, а
единственное работающее — [прототип](../../prototype/feed-board.html).
Страницы появятся вместе с кодом, который они описывают.

## Технические области {#technical-areas}

| Область | Slug | Граница |
|---|---|---|
| Доска | `board` | Три вида, сетка профиля, ритм, фильтры, перетаскивание и порядок очереди |
| Содержание | `content` | Форма поста, линии и ветки, метки, состояния, сторис как слой |
| Данные | `data` | Где лежат посты и обложки, чтение, запись, перенос между машинами |
| Интерфейс | `frontend` | UI-примитивы, всплывающие элементы, тема, язык, движение |
| Среда разработки | `development` | Команды, lint и typecheck, окружение |

Область без ссылки ещё не описана: ссылка появляется вместе с её первой
страницей.

Новый slug добавляется, только если ни одна существующая область не владеет
материалом. Граница новой области записывается в эту таблицу в том же коммите.
